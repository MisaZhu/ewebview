sdlbrowser

A minimal SDL2 desktop browser powered by ewebview.

Quick Start

  • Type a URL in the address bar and press Enter
  • Use the < button (or Alt+Left) to go back
  • Use the X button (or Escape) to stop loading
  • Use the R button (or F5) to refresh
  • Scroll with the mouse wheel
  • Ctrl+L focuses the address bar

About ewebview

ewebview is a self-contained embedded web engine that renders HTML/CSS/JS to an abstract ARGB8888 memory canvas. Platform dependencies are injected via HAL callback tables (gfx, font, image, net, clock, sys).

Core Technologies

Renderinglitehtml (with Gumbo HTML5 parser)
JavaScriptmario bytecode VM (ES5 + ES6+)
Image DecodeSDL2_image + libwebp
Networkinglibtinyhttpsc (BearSSL HTTP/HTTPS)
GraphicsSDL2 + SDL2_gfx + SDL2_ttf

Architecture

sdlbrowser/
  main.c          SDL2 window shell + toolbar + event loop
  Makefile        build rules (links libewebview + SDL2)
  res/
    default.html  this page
    default.css   master stylesheet

ewebview/         the web engine library
  src/            core (C++14, platform-independent)
  porting/sdl2/   SDL2 HAL port (C99)
  include/        public C API headers

Threading Model

The engine thread owns the litehtml documents, the mario VM, and all parsing/styling/layout/rasterization. The UI thread (this SDL2 app) talks to the engine only through non-blocking queued commands and drains events via ewebview_tick().
